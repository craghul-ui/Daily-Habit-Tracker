# Daily Habit Tracker

A clean, beginner-friendly habit tracker built with **HTML, CSS, and vanilla JavaScript**. Add habits, mark them complete, and see your daily progress.

## Features
- Add and delete habits
- Mark habits as completed
- Progress bar and completion count
- Clear completed habits
- Saves your list in the browser with `localStorage`
- Responsive layout for mobile and desktop

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start adding habits!

No installation or build tools required.

## Built with
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project preview
Open `index.html` in a browser to view the app.
